# 한찬희 포트폴리오

백엔드 개발자 한찬희의 포트폴리오 웹사이트입니다.

## 소개

Spring Boot로 RESTful API를 설계하고 데이터베이스를 모델링하며, AI 기술을 웹 서비스에 통합해왔습니다.
클라우드 기반 배포와 운영 경험을 바탕으로 실제 서비스에 필요한 기능을 안정적으로 구현하는 역량을 쌓아왔습니다.

16개월의 교육 과정과 4개의 프로젝트를 통해 웹 개발의 기초를 다졌고, 팀장 경험과 해외 근무를 통해 협업과 적응력을 키웠습니다.
실제 운영 서비스를 유지보수하며 안정적인 서비스 운영의 중요성도 함께 배웠습니다.

## GitHub Pages 배포

정적 사이트이므로 GitHub Pages에서 바로 배포할 수 있습니다.

1. GitHub 저장소를 생성합니다.
2. 이 프로젝트 파일들을 업로드합니다.
3. GitHub 저장소에서 Settings > Pages로 이동합니다.
4. Source를 `Deploy from a branch`로 설정합니다.
5. Branch는 `main`, Folder는 `root`를 선택합니다.
6. 배포가 완료되면 다음 형식의 URL이 생성됩니다.

```text
https://{username}.github.io/{repository-name}/
```
